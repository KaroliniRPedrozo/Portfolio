Projetos

ChronosBotno ar

FastAPI · React · PostgreSQL/pgvector · ChromaDB · Gemini · código

Tutor de História e Geografia com IA. O professor monta a base de conhecimento de cada turma e os alunos fazem perguntas; as respostas são geradas pelo Gemini com RAG em cima desse material.

  • Embeddings e respostas pela API do Gemini.
  • Geração de embeddings em paralelo com ThreadPoolExecutor (5 workers).
  • Banco no Neon, API no Render e frontend na Vercel.

Cypher's Analytics

.NET/C# · React · TypeScript · PostgreSQL · Riot API · código

Reúne e analisa dados de partidas a partir da API da Riot Games.

  • Backend em .NET/C# com Clean Architecture e endpoints REST assíncronos.
  • Frontend em React com TypeScript e estado global.
  • Modelagem relacional e otimização de consultas no PostgreSQL.
