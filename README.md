# Portfólio — Karolini R. Pedrozo

Meu site pessoal, em português e inglês, com projetos, experiência e contato.

**Demo:** https://karolinirpedrozo.github.io/Portfolio/

## Estrutura

```
index.html      conteúdo da página (texto em português)
css/style.css   estilos, com modo claro e escuro
js/main.js      troca de idioma e textos em inglês
img/foto.jpg    foto de perfil
```

Não tem build: é só abrir o `index.html` no navegador ou publicar a pasta no GitHub Pages.
